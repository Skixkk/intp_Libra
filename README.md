## Overview

This repo collects structured observations, behavioural patterns, strengths, blind spots, workplace traits, social & friendship compatibility, cognitive conflict analysis for **INTP (Ti-dom) + Libra**.

This combination creates a persistent internal tension:

- INTP: chase logical consistency, root-cause reasoning, abstract modeling, resist emotional coercion
- Libra: crave peaceful atmosphere, fair tradeoffs, avoid confrontation, weigh multiple viewpoints, hesitate under uncertainty

The materials here are for **self-reference, pattern summarization and self-regulation**, not rigid psychological diagnosis.
