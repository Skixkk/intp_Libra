# intp_Libra

> INTP + 天秤座原型系统化自我观察笔记库
> 内核由逻辑驱动，外层承载天秤座对平衡、和谐与多方视角权衡的追求。

[![markdownlint](https://img.shields.io/badge/lint-markdownlint-blue)](https://github.com/DavidAnson/markdownlint)
[![Conventional Commits](https://img.shields.io/badge/commit-conventional--commits-orange)](https://www.conventionalcommits.org/)
[![License](https://img.shields.io/badge/license-MIT-green)](LICENSE)

## 概述

本仓库整理 **INTP（Ti主导）+ 天秤座** 的结构化观察记录：行为模式、优势特质、盲区短板、职场表现、交友适配性以及内在认知冲突分析。

该组合长期存在一组内在张力：

- INTP：追求逻辑自洽、溯源推理、抽象建模，抗拒情绪绑架
- 天秤座：偏好氛围平和、公平折中、回避正面冲突，习惯多方权衡，容易在不确定中犹豫

仓库内容仅用于**自我复盘、规律总结与行为调节**，不构成标准化心理诊断。

## 内容目录

1. 核心特质融合：Ti逻辑与天秤平衡偏好之间的内在冲突
2. 社交与交友适配分析：契合、高摩擦的MBTI人格类型
3. 职场特质：优势、典型陷阱、决策偏误、适配岗位方向
4. 认知陷阱：分析瘫痪、冲突回避、过度设计、为和谐牺牲逻辑
5. 自我调节方案：限时决策、边界建立、“够用即可”交付原则
6. Markdown 校验配置：markdownlint 规则（含 MD029 有序列表规范）

## 仓库规范

- Markdown：遵循 markdownlint，MD029 设置为 `one_or_ordered`，兼容两种有序列表写法
- Git 提交：严格遵守 **Angular 规范提交信息（英文 + Emoji）**
- 分支流程：主干开发模式（Trunk-Based Development），禁止直接推送至 main，必须走 PR
- 行文基调：描述性、分析向、低情绪化，保持结构对称工整
